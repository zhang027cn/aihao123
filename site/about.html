ℹ️ 关于本站

AI Hao123 是一个只做 AI 的中文导航站：精选 AI 工具入口、聚合每日 AI 资讯、 提供可复算的开源排行榜，并搜集公开免费、开源的 MCP 与 SKILL 目录。

内容范围严格限定在 AI 领域，不涉及任何其它方面。

🧱 技术方案

  • 纯静态站点（HTML/CSS/JS），零框架、零构建依赖
  • Node 数据管线（零 npm 依赖），公开 API 抓取落盘为 JSON
  • GitHub Actions 每 4 小时自动更新数据并推送
  • 托管于 GitHub Pages，免费 HTTPS

📡 数据来源

  • 资讯：15+ 个公开 RSS / 官方博客 / Hacker News
  • 榜单：GitHub Search API、Hugging Face API、HN Algolia
  • MCP：registry.modelcontextprotocol.io 官方 Registry
  • SKILL：anthropics/skills 官方仓库 + GitHub 开源仓库

⚖️ 收录与免责

导航目录由人工精选；MCP / SKILL 目录只收录公开免费、开源的项目（OSI 认可许可证、未归档），宁缺毋滥。 所有资讯仅保留标题、摘要与原文链接，版权归原媒体所有。本站不存储任何模型权重或版权内容。

完整开发计划见仓库 PLAN.md。
